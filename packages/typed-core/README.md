# @streaming-hub/typed-core

Gemeinsame Logik und Datenmodelle für Streaming-Hub Desktop (Electron) und iOS/AppleTV (Swift/SwiftUI).

## Ziel

- **Single Source of Truth** für Sender-Listen, Dienste-Definitionen und Konfiguration
- **TypeScript → JSON Schema** – Swift kann dieselben Strukturen nativ nutzen
- **Plattform-unabhängig** – null UI, null Electron, null DOM
